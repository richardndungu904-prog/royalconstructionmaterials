# Royalconstructionmaterials

## Project architecture

This is a TanStack Start / React 19 construction-materials store, deployed on Netlify. Routes are file-based and generated by TanStack Router during the platform build. Vite integrates TanStack Start, React, Tailwind CSS and Netlify. Do not edit generated route-tree files.

The storefront is WhatsApp-first: it has no online payments, customer accounts or admin login. Keep this requirement intact. Quote submissions are saved but are not orders; customers must continue to WhatsApp and send their prepared message to the sales agent.

## Key directories

- `src/routes/`: homepage, product catalogue and detail routes, quotation, price guide, about and contact pages. `api.cart.ts` and `api.quotation.ts` contain server-only API handlers.
- `src/components/`: shared layout, navigation, native-dialog cart drawer, cart context, catalogue filters and product cards.
- `src/data/products.ts`: static editorial catalogue, source-derived prices, typed variants, photo mappings and server-side selection validation.
- `src/lib/contact.ts`: authoritative phone, WhatsApp, email, Facebook and location links from the uploaded contact document.
- `src/lib/cart-server.ts`: server-only anonymous cart session helpers and database reads. Do not import this module from client components.
- `src/styles.css`: charcoal-and-gold design tokens, custom layouts, responsive breakpoints and reduced-motion rules. Typography pairs Barlow Condensed with Manrope.
- `db/schema.ts`: Drizzle schema for persistent carts and quotation snapshots. `db/index.ts` initializes the Netlify Database adapter.
- `netlify/database/migrations/`: deploy-time schema migrations generated by Drizzle Kit. Keep applied migrations immutable.
- `public/img/`: 164 deduplicated supplied images, named `material-<reference-number>.jpg`, with one PNG logo asset.
- `public/resources/`: original supplied instruction and contact documents.

## Data and security

Use Netlify Database for customer state. Do not introduce local storage, JSON files or process-memory persistence for baskets or quotations. React state mirrors the server-owned basket only. The public product catalogue is immutable editorial content, not a writable application database.

The anonymous cart identifier is an unguessable UUID in an HttpOnly, SameSite cookie. Database mutations must be scoped to that identifier. Never expose quotation lists or customer records through an unauthenticated read endpoint. Validate all inputs with Zod, check same-origin mutations and derive product prices from the trusted catalogue, never client-submitted amounts. Quotations retain a basket snapshot and have a server-side per-cart submission cooldown and a honeypot field.

Import the Drizzle adapter from `drizzle-orm/netlify-db`, using the configured beta dependencies. Use `.js` extensions for imports within the root `db` modules. Schema changes require a corresponding generated migration under `netlify/database/migrations/`.

## Content decisions

Use the current per-metre prices: box profile 400, ordinary 350, corrugated 300, versatile 650, Roman tile 650, ordinary reject 150 and box-profile reject 200, all in KSh. Dumuzas G30 has explicit 1m / 2m / 2.5m / 3m prices of 350 / 700 / 850 / 1050. The separate KSh 378 charcoal box-profile promotion has unclear units and must not silently replace the explicit standard price.

Items without source pricing use `null` and “Request price”; do not invent a price or count these as free. Cart subtotals exclude quote-only items and delivery, with visible explanations. Reject photos are references, not proof of current condition. Avoid fabricated stock counts, reviews, years in business, delivery promises or opening hours.

The map is an area-level Nakuru Pipeline map. An exact storefront location was not supplied. Ask visitors to confirm the collection point with sales.

## Coding conventions

Use TypeScript, functional React components, descriptive names, PascalCase components and camelCase utilities. Use the `@/` alias for source imports. Keep persistence and customer data on the server. Do not add code comments or unrelated features. Use Lucide icons rather than emoji. Keep native dialog focus trapping, Escape dismissal, clear form labels, accessible image descriptions, loading/error/empty states and responsive layouts.

Use `imageUrl()` to render supplied images through Netlify Image CDN. Keep the original photos in the project rather than referencing the attachment directory. Source price guides may link to their full-size originals. The platform supplies the social sharing image, so do not add `og:image`.

## Working on this project

Read the applicable platform skills before implementing Netlify features. Use `apply_patch` for code edits. Never inspect `.git`, print credentials, create commits or start a local build/test/dev server in an automated Build mode session. The platform validates and builds after changes. Code-generation utilities such as Drizzle migration generation are allowed. A fresh production database branch is expected to become available when the site is deployed.

Local human development uses `pnpm install` followed by `netlify dev --port 8889`. Automated change summaries are written to `.netlify/results.md` in past-tense, standalone prose.
